# Web (Phaser / Three.js / Babylon.js) — UI Reference

> Pinned to Phaser 3.80+, Three.js r160+, Babylon.js 7.0+. Verify anything newer against https://phaser.io/ and https://threejs.org/docs/.

## Core types & entry points
- Phaser: `Text`/`BitmapText`, DOM elements via `dom.createElement`
- Three.js/Babylon: HTML/CSS overlay or CSS2DRenderer
- Babylon.js GUI: `@babylonjs/gui` `AdvancedDynamicTexture`
- Pointer/keyboard input via DOM or engine input managers
