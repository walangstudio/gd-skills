# Web (Phaser / Three.js / Babylon.js) — Navigation Reference

> Pinned to Phaser 3.80+, Three.js r160+, Babylon.js 7.0+. Verify anything newer against https://phaser.io/ and https://threejs.org/docs/.

## Core types & entry points
- No standard built-in navmesh in any of the three
- Three.js: `three-pathfinding` (recast navmesh) community lib
- Babylon.js: `RecastJSPlugin` navigation
- Phaser: grid/tile A* via plugins (e.g. `easystar.js`)
