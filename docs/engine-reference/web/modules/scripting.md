# Web (Phaser / Three.js / Babylon.js) — Scripting Reference

> Pinned to Phaser 3.80+, Three.js r160+, Babylon.js 7.0+. Verify anything newer against https://phaser.io/ and https://threejs.org/docs/.

## Core types & entry points
- JavaScript ES6+: classes, arrow fns, `async`/`await`, modules
- Phaser scene methods; Three.js `requestAnimationFrame` loop
- Event emitters (`scene.events`) and DOM events
- TypeScript optional but common for all three
