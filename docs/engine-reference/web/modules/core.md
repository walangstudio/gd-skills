# Web (Phaser / Three.js / Babylon.js) — Core Reference

> Pinned to Phaser 3.80+, Three.js r160+, Babylon.js 7.0+. Verify anything newer against https://phaser.io/ and https://threejs.org/docs/.

## Core types & entry points
- Phaser: `Phaser.Game` config + `Scene` (`preload`/`create`/`update`)
- Three.js: `Scene` + `PerspectiveCamera` + `WebGLRenderer` render loop
- Babylon.js: `Engine` + `Scene` + `engine.runRenderLoop`
- ES6 modules; bundlers (Vite/webpack) or CDN imports
