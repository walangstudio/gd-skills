# Unity 6 — UI Reference

> Pinned to Unity 6 (2023 LTS) / 2023.2+. Verify anything newer against https://docs.unity3d.com/.

## Core types & entry points
- uGUI: `Canvas` + `RectTransform` + `Image`/`Text`/`Button`
- UI Toolkit (UIElements): `UIDocument` + USS/UXML for runtime UI
- `EventSystem` required for input
- TextMeshPro for crisp text
