# Unity 6 — Physics Reference

> Pinned to Unity 6 (2023 LTS) / 2023.2+. Verify anything newer against https://docs.unity3d.com/.

## Core types & entry points
- 3D: `Rigidbody` + `Collider`; 2D: `Rigidbody2D` + `Collider2D`
- `FixedUpdate` for physics; `OnCollisionEnter`/`OnTriggerEnter` callbacks
- `Physics.Raycast` / `Physics2D.Raycast`
- Layers + collision matrix in Project Settings
