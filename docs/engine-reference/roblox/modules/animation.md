# Roblox 2025+ — Animation Reference

> Pinned to Roblox 2025+. Verify anything newer against https://create.roblox.com/docs.

## Core types & entry points
- `Animation` (asset id) + `Humanoid:LoadAnimation()` -> `AnimationTrack`
- `AnimationTrack:Play()`/`:Stop()`, `:AdjustSpeed()`
- `Animator` on Humanoid/AnimationController
- `TweenService:Create(inst, TweenInfo, goal)` for property tweens
