# Unreal Engine 5.4+ — UI Reference

> Pinned to Unreal Engine 5.4+. Verify anything newer against https://dev.epicgames.com/documentation/en-us/unreal-engine.

## Core types & entry points
- UMG: `UUserWidget` + Blueprint widgets; Slate underneath
- `UWidgetComponent` for world-space UI
- `AddToViewport()` to show widgets
- Bind via `UPROPERTY(meta=(BindWidget))`
