# Unreal Engine 5.4+ — Core Reference

> Pinned to Unreal Engine 5.4+. Verify anything newer against https://dev.epicgames.com/documentation/en-us/unreal-engine.

## Core types & entry points
- `AActor` base; `APawn`/`ACharacter` controlled by `AController`/`APlayerController`
- `UWorld`, `ULevel`, `GameMode`/`GameState`/`PlayerState`
- `UObject` reflection via `UPROPERTY`/`UFUNCTION`/`UCLASS` macros
- `TObjectPtr<>` for UPROPERTY object refs (5.3+)
